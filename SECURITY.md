# Security policy

## Reporting a security problem

To report a security problem, open a GitHub issue titled `Security report` at
https://github.com/florinel-chis/GopherCRM/issues.

Keep the issue brief: describe only the affected area (for example "form submissions" or "API key
authentication"). Leave out exploit details, reproduction steps and any proof of concept, since
issues are public.

The maintainer then gets in touch with you to take the details further.

## Supported versions

Only the latest release is supported. Check that a problem still occurs on it before you report it.
